# Реализованные возможности

| Часть | Состояние |
|---|---|
| Сборка | Пять Gradle-модулей, Kotlin DSL, Java 21, библиотечные JAR и архивы исходников |
| Параметры | Неизменяемый `StudentParameters(c, s, k)` с проверкой конечности и положительности |
| Интерфейс | JavaFX-оболочка с пятью разделами и пустыми состояниями; отдельный ViewModel |
| Подключение библиотеки | Самостоятельный пример вычисляет принадлежность и крайние α-сечения через готовый JAR без JavaFX |
| Ограниченная величина | `BoundedStudentFuzzyNumber` реализует `FuzzyNumber`, вычисляет принадлежность, замкнутый носитель и аналитические α-сечения. Конструктор проверяет ε и конечность границ носителя |
| Вычисления | Арифметика, ранжирование, генераторы и кластеризация пока не реализованы |
| Прикладные сценарии | Эксперименты, снимки, запуски и отмена пока не реализованы |
| Файлы | JSON, CSV и журнал пока не реализованы |

В algorithms, application и io зарезервированы пакеты для будущей реализации.

Целевое поведение описано в [требованиях](requirements.md),
[математической модели](math-model.md) и [процессах](processes.md).
