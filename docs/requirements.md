# Назначение и требования

Student Lab представляет и обрабатывает нечёткие величины с функцией принадлежности
на основе нормированной формы Стьюдента и явным ограничением слабых хвостов.
Приложение работает локально; вычислительные библиотеки доступны внешним Java-программам.

## Основные функции

| Функция | Результат |
|---|---|
| Задать или изменить величину | Проверенная запись величины и новый снимок набора |
| Исследовать величину | Принадлежность μ(x), α-сечение и замкнутый носитель |
| Выполнить операцию | Сумма, разность, произведение, допустимое частное или сравнение рангов |
| Сгенерировать набор | От 100 до 300 полных нечётких величин и настройки воспроизведения |
| Кластеризовать набор | K непустых групп и история объединений |
| Сохранить и загрузить эксперимент | JSON с величинами, настройками, снимками и результатами |
| Экспортировать результат | CSV с явными колонками и настройками вычисления |
| Просмотреть журнал | Записи со значениями входов, результатами и исходами действий |

## Математическая модель

Исходная величина задаётся конечным центром c, конечным масштабом s>0,
положительным целым числом степеней свободы k и параметром 0<ε<1.
Принадлежность принимает значения от 0 до 1 и не является вероятностью.
Масштаб s не следует называть стандартным отклонением.

Значения по умолчанию: k=5, ε=0.001. При генерации одного набора k и ε общие,
а c и s выбираются независимо и равномерно в заданных диапазонах.
Seed, алгоритм PRNG, диапазоны и порядок объектов сохраняются.

Арифметика использует общую сетку α: 0, 0.01, …, 1. Результат хранится как таблица
конечных вложенных интервалов и может участвовать в следующих операциях.
Он не обязан сохранять форму Стьюдента. Деление отклоняется целиком, если замкнутый
носитель делителя содержит ноль. NaN, бесконечность и переполнение дают численную ошибку.

Сравнение использует среднее середин сечений на общей сетке.
Совпадение рангов означает равенство по критерию, а не совпадение функций.

Кластеризация — агломеративная со средней связью. Расстояние использует две границы
одного общего сечения при 0<α<1. Для N объектов задаётся целое 1≤K≤N;
каждый объект входит ровно в одну группу. При равных расстояниях используются
стабильные идентификаторы входного снимка. История содержит N−K объединений.

Дополнительный режим создаёт обычную числовую выборку Стьюдента без ε-преобразования.
Он не заменяет генерацию нечётких объектов. Формулы и численные ограничения —
в [математической модели](math-model.md).

## Интерфейс

Разделы: «Величины», «Операции», «Генерация», «Кластеры», «Журнал».
Подписи краткие; определения доступны в справке или подсказках.

- График принадлежности имеет ось μ от 0 до 1, выбор объекта, точки x и уровня α.
  Видны значение μ(x), границы сечения и статус «В α-сечении» / «Вне α-сечения».
  Для α=0 используется замкнутый носитель, а не условие μ(x)≥0.
- Арифметика показывает операнды, действие, результат и таблицу сечений.
  Добавление результата в набор — явное действие пользователя.
- Сравнение показывает критерий и ранги; кластеризация — α, K и состав групп.
- Старый результат остаётся связан с прежними входами после изменения настроек.
- Длительные расчёты выполняются в фоне с прогрессом и отменой.
  Отмена до публикации отбрасывает частичный результат.
- Ошибки параметров видны возле полей или в понятном сообщении.
  Сбой журнала отображается отдельно от исхода вычисления.

## Данные и файлы

Снимки неизменяемы. Редактирование создаёт новую запись величины и новый снимок,
сохраняя входы прежних результатов. Поздний ответ фоновой задачи не подменяет
другой эксперимент или новые входные данные.

JSON содержит версию формата, настройки, представления величин, снимки, запуски
и результаты со ссылками. Загрузка полностью проверяет кандидат состояния до его
применения; ошибка сохраняет текущее состояние. Неизвестный формат отклоняется.

JSON и CSV записываются во временный файл рядом с целевым с последующей атомарной
заменой. Если она недоступна, возвращается ошибка, а прежний файл сохраняется.

Журнал JSON Lines содержит requestId, при наличии runId, время события, действие,
настройки, исход, коды ошибок и фактические входные и выходные значения.
Чтение журнала не записывает само себя. Сбой записи не меняет исход вычисления.

## Устройство

Java 21, Gradle Kotlin DSL, JavaFX. Пять модулей разделяют математические значения,
алгоритмы, прикладные сценарии, файловые адаптеры и интерфейс.
Библиотечный API синхронный; потоками управляет вызывающая сторона.
Подробности — в [архитектуре](architecture.md) и [процессах](processes.md).
